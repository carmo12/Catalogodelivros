# 📚 Catálogo de Livros

Aplicação mobile desenvolvida com **React Native, Expo e TypeScript** para apresentação e organização de um catálogo de livros.

O projeto foi desenvolvido com foco em uma interface simples, organizada e de fácil utilização, utilizando componentes reutilizáveis para a apresentação das informações dos livros.

---

## 🚀 Tecnologias utilizadas

- ⚛️ React Native
- 📱 Expo
- 🟦 TypeScript
- 🧭 Expo Router
- 📦 Node.js / npm
- 🐙 Git e GitHub
